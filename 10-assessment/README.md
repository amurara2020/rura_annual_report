# Implementation and completion assessment

The management layer of the project: what state each section is in, what is missing, who owns it,
and in what order it should be done.

| File | Purpose |
| :-- | :-- |
| `00_implementation_assessment.md` | The assessment: headline findings, the four required gap categories, regulatory-effectiveness analysis, blocked items, recommended sequence |
| `completion_matrix.csv` | **The main working output.** 73 rows, one per section, 13 columns from Part/Chapter through to verification notes |
| `02_priority_items.md` | The 15 highest-priority items required to complete the report |
| `05_structural_flags_and_length_control.md` | Structural contradictions flagged for decision; main-report vs annex recommendations |

## The matrix columns

`Part/Chapter` · `Section` · `Current Status` · `Existing Content (usable)` ·
`Missing Content / Data` · `Required KPI / Analysis` · `Proposed Visual` ·
`Data Required (specific variables)` · `Likely Data Source` · `Responsible Owner` ·
`Action Required` · `Priority` · `Notes / Verification Required`

Open it in Excel or Sheets and filter by `Responsible Owner` to produce each team's worklist, or by
`Priority` to scope the report.

## Priority convention

- **Priority 1** — Essential for the FY2025/26 Annual Report
- **Priority 2** — Include if data can be obtained within the reporting timeline
- **Priority 3** — Future reporting improvement, FY2026/27 onward

The prioritisation matters: **the FY2025/26 report should not be delayed in pursuit of an ideal
future-state report.**
