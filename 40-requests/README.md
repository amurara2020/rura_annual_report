# Information requests

| File | Purpose |
| :-- | :-- |
| `information_requests_to_departments.md` | The requests themselves, written to be sent as-is, one section per recipient |
| `request_tracker.csv` | 71 tracked requests with recipient, item, sections unblocked, priority, dates and status |

## How to use the tracker

Fill `Date Requested` and `Due Date` when a request goes out; `Status` and `Date Received` on
arrival. Register each received file in `../00-source/SOURCES.md` with its Drive ID.

## Two requests that block the most

- **`REQ-01` — the M&E Framework.** Unblocks all of chapter 2 (9 goals and 17 initiatives, every one
  currently "Not assessed"), Annex 9.4, headline tile 15, and the target markers on every sector KPI
  card. **It is cited by the baseline but could not be found in Drive** (`REQ-71`).
- **`REQ-44` / `REQ-61` — the AFC / e-ticketing data feed.** Longest lead time of anything on the
  list and the highest analytical payoff. Request it first even though it is analysed last. Ask for a
  standing feed, not a one-off extract.

## Framing to include in every request

> Where a figure does not exist, please say so explicitly rather than estimating. The report will
> mark it as requiring data. An estimate that cannot be sourced is worse than an acknowledged gap.
