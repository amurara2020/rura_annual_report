# Information and Data Requests — FY2025/26 Annual Report

One section per recipient, ready to send. Each request states the **specific variables** required, the **reference period**, the **disaggregation**, and **which section of the report it unblocks** — so recipients can see why it matters and cannot return "data not available" without saying which variable.

**Suggested framing for all requests:** *Where a figure does not exist, please say so explicitly rather than estimating. The report will mark it as requiring data. An estimate that cannot be sourced is worse than an acknowledged gap.*
