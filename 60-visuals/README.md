# Visuals

## `specs/visual_specifications.csv`

44 visuals specified with: title, chapter, type, variables required, time period, disaggregation,
data source, responsible team, intended regulatory message, current status and priority.

The `Intended Regulatory Message` column is the test a visual has to pass. A chart that cannot
state one does not belong in the report — the brief is explicit that decorative visuals which
communicate no regulatory insight should be avoided.

## `output/`

Rendered charts. Source data must come from `../30-data/processed/` or
`../30-data/statistical-annex/`, never typed in by hand.

## The visual standard

The baseline document cites a separate **RURA Visual Design Standard** as the authority for chart
styling. **It could not be found in Drive** and is recorded as `REFERENCED-MISSING` in
`../00-source/SOURCES.md` (`REQ-70`). Obtain it before producing final charts, or the report will
be styled inconsistently with the standard it claims to follow.

## Three charts cannot currently be reproduced

The owned-fibre chart, Figure 3.12 and Figure 3.17 exist in the baseline **only as images**, with no
underlying data. They cannot be corrected, recoloured, translated or checked. Data requested under
`REQ-24` and `REQ-33`; tracked as `CHK-30`.
