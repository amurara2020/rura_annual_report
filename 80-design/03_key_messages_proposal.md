# Key messages — design proposal

**Wording unchanged in every option.** Only the presentation differs.

## The problem

The two key messages carry findings of **opposite valence**:

- *Mobile penetration passed 100…* — an achievement
- *Fixed broadband remains marginal… and declined* — a concern

Both currently get the same black square (■). The reader has to parse each full sentence to work out which is good news. Standard §11 already requires status to be carried by **symbol + word + colour**; the key-messages block is the one component where that rule is not applied.

## Four options

| | Treatment | Character | Use when |
| :-- | :-- | :-- | :-- |
| **1** | Status-ruled | Closest to current; a coloured left rule and a status word | Minimal change wanted |
| **2** | Figure-anchored | The number carries the message, matching the KPI cards above | **Recommended** |
| **3** | Editorial numerals | Quietest; sector-coloured 01/02, arrow only | The opener is already busy |
| **4** | Panels | Most prominent; side-by-side tinted panels | Key messages should compete with the cards |

All four use existing tokens. No new colours.

## Why Option 2

The block sits directly beneath the At-a-Glance KPI cards, which already present *figure → label → status*. Option 2 repeats that grammar one level down, so the opener reads as one system rather than a card row followed by an unrelated bullet list. It is also the most scannable: a reader taking five seconds gets `100 ▲ improved` and `84,152 ▼ watch` without reading a sentence.

Option 1 is the safe choice if the change needs to be small. Option 4 is the one to avoid unless the cards are removed — two competing emphasis blocks on one page.

## Two things to decide

**1. Repetition of 84,152.** In Option 2 the figure appears as the anchor *and* in the parenthetical — and a third time in the KPI card above. Either drop the parenthetical in the message, or anchor message 2 on a different figure. This is a wording decision, so it is left as it stands.

**2. "Watch" or "worsened" for fixed broadband.** The message says the decline followed removal of inactive users, which is a data-cleaning effect rather than a service failure. `watch` is used here as the softer reading; `worsened` is available if the sector department judges the decline real.
